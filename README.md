# Carryover

**Will his game travel?**

Carryover is an open-source football-intelligence project investigating
whether a striker's performance and role can transfer into a specific
team, coach and tactical environment.

## Research question

Does adding destination-team, tactical-role, coach and squad context
improve out-of-time prediction of first-season utilization and
performance compared with evaluating the player alone?

## First public case

Loïs Openda → Juventus, reconstructed using only information available
at the time of the transfer.

## Current status

Research preview. No predictive claims yet.

## Principles

- Point-in-time correctness: no future information
- Explainability before complexity
- Player quality is not the same as player-context fit
- Public methodology, predictions and mistakes
- No speculative mentality or personality scoring

## Initial outputs

1. Opportunity risk
2. Performance-regression risk
3. Role-suppression risk
4. Evidence confidence

## Project roadmap

1. Define the research problem
2. Audit legally usable data
3. Build a reproducible historical transfer dataset
4. Establish a player-only baseline
5. Test whether context improves prediction
6. Publish frozen case reports
